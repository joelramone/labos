# Glossary

Definiciones de términos clave usados en LabOS.

## Términos

| Término | Definición |
|---------|-----------|
| Lab | Vertical de negocio independiente dentro del portafolio |
| Package | Unidad de trabajo con entregables concretos |
| Activo | Artefacto reutilizable producido por investigación o trabajo |
| Blueprint | Diseño documentado antes de implementación |
| Steering | Documento de reglas permanentes para guiar al agente de IA |
| Spec | Especificación formal de feature o bugfix (Kiro) |
| ADR | Architecture Decision Record — registro de decisión |

> Este glosario se expandirá conforme el proyecto avance.
