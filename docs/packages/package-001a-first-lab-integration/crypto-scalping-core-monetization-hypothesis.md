## NON-GOALS explícitos

Estas NO son hipótesis de monetización y NO deben perseguirse: [Decisión]

| Non-goal | Razón |
|----------|-------|
| Vender señales de trading | NO hay estrategia rentable — sería fraudulento [Hecho] |
| Ofrecer asesoramiento financiero | Proyecto educativo/experimental — sin licencia ni qualificación [Hecho] |
| Garantizar retornos | Expectancy negativa en 100% de configuraciones probadas [Hecho] |
| Trading live con capital real (como servicio) | No hay edge demostrado [Hecho] |
| Copy-trading o managed accounts | Sin estrategia viable + regulación [Hecho] |
