# Decisions

Registro de decisiones arquitectónicas y de negocio (ADRs).

## Formato

Cada decisión sigue la convención: `NNNN-titulo.md`

Ejemplo: `0001-stack-selection.md`

## Contenido de un ADR

- Contexto: ¿por qué se necesita esta decisión?
- Opciones consideradas.
- Decisión tomada y justificación.
- Consecuencias.
- Fecha y autor.
