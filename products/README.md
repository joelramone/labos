# Products

Blueprints y documentación de productos del portafolio LabOS.

## Contenido futuro

Cada producto tendrá una carpeta con:

- Product brief.
- Hipótesis de monetización.
- Estado de validación.
- Roadmap.

## Regla

No documentar un producto como "lanzado" o "validado" sin evidencia de pago o uso real.
