# Hypothesis Register — Human Performance 40+

Todas las entradas están en estado `[Hipótesis]` hasta obtener evidencia.

| ID | Hipótesis | Prioridad | Evidencia de validación mínima |
|---|---|---|---|
| H-PROBLEM-01 | Existe al menos un problema de entrenamiento frecuente, importante e insuficientemente resuelto para el segmento aproximado 40–55. | P0 | Patrón repetido en entrevistas/observación y evidencia conductual |
| H-PAY-01 | Un subconjunto pagará por una experiencia productizada que resuelva ese problema. | P0 | Compromiso monetario, depósito, preventa o compra |
| H-APP-01 | Human Performance 40+ App es una solución competitiva. | P1 | Supera una alternativa manual/híbrida en prueba comparativa |
| H-TRACK-01 | Tracking estructurado aumenta percepción de progreso y adherencia. | P1 | Uso sostenido y cambio de conducta frente a baseline |
| H-TRACK-02 | Un conjunto pequeño de métricas aporta más valor que registrar todo. | P1 | Usuarios identifican y usan métricas para decidir/progresar |
| H-GAME-01 | Gamification aumenta motivación/adherencia sin inducir conducta riesgosa. | P1 | Mejora observable + ausencia de señales de sobreuso/presión |
| H-COMM-01 | Pertenencia aumenta conexión emocional y continuidad. | P1 | Participación voluntaria y retención cualitativa/conductual |
| H-MOVE-01 | Video de smartphone puede producir feedback técnico útil para movimientos seleccionados. | P0 técnico | Acuerdo suficiente con evaluación humana y abstención segura |
| H-MOVE-02 | Feedback positivo técnicamente específico mejora aprendizaje y motivación. | P1 | Usuarios comprenden, recuerdan y aplican el feedback |
| H-WL-01 | Halterofilia es un caso inicial útil para delimitar Movement Analysis. | P1 | Observabilidad y demanda suficientes para un scope acotado |
| H-MSP-01 | Puede venderse una oferta manual o híbrida antes de una app completa. | P0 comercial | Primera transacción con entrega responsable |
| H-CAP-01 | Movement Analysis podría reutilizarse entre varios Labs o Products. | P2 futuro | Casos independientes validados en más de un dominio |

## Status rules

- [Decisión] `proposed` es el estado inicial de todas las hipótesis.
- [Decisión] Una hipótesis sólo pasa a `supported` con evidencia citada; pago requiere conducta monetaria.
- [Decisión] Resultados negativos o ambiguos se registran; no se reinterpretan como validación.
