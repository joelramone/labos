# Evidence Capture Template — Phase 1 Interview

> One copy per interview. Capture minimum necessary information. Do not include full name, medical history, body images or video.

## Metadata

| Field | Value |
|---|---|
| Evidence ID | `{HP40-P1-EV-NNN}` |
| Participant ID | `{HP40-P-NNN}` |
| Interview date | `{YYYY-MM-DD}` |
| Researcher | `{role}` |
| Consent for notes | `{yes/no}` |
| Follow-up permission | `{yes/no; minimal channel stored separately if needed}` |

## Segment and context

| Field | Evidence |
|---|---|
| Segment hypothesis | `{one or more recruitment hypotheses}` |
| Training context | `{home/gym/club/other; current behavior}` |
| Experience context | `{behavioral summary; avoid unnecessary demographics}` |

## Behavioral evidence

| Field | Evidence |
|---|---|
| Current behavior | `{what participant actually does}` |
| Problem observed/reported | `{specific event, not generalized claim}` |
| Frequency | `{participant-described recurrence + concrete examples}` |
| Consequence | `{time, effort, abandonment, performance, emotional or economic consequence}` |
| Existing solution | `{tool/person/program/workflow currently used}` |
| Existing expenditure | `{actual category/range if voluntarily disclosed; no hypothetical price}` |
| Workaround | `{what they do when problem appears}` |
| Switching behavior | `{what changed, trigger, rejected alternatives}` |

## Evidence assessment

| Field | Entry |
|---|---|
| Quote summary | `{short paraphrase; avoid excessive verbatim transcription}` |

| Researcher interpretation | `{separate from participant evidence}` |

## Data minimization check

- [ ] No full name captured.
- [ ] No medical history requested.
- [ ] No video/body image captured.
- [ ] Injury-related comments, if volunteered, are summarized without clinical interpretation.
- [ ] Only evidence relevant to the Research Question is retained.
