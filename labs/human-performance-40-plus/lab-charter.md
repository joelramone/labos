# Lab Charter — Human Performance 40+ Lab

## Purpose

[Decisión] El Lab investiga el problem space antes de seleccionar una solución, y busca evidencia de pago antes de comprometerse con software completo.

## In scope

- Problemas, objetivos, comportamientos y alternativas actuales de adultos aproximadamente entre 40 y 55 años respecto del entrenamiento.
- Fuerza, masa muscular, acondicionamiento, movilidad, habilidades deportivas, consistencia y experiencia de entrenamiento.
- Hipótesis de tracking, gamification, belonging/community y Movement Analysis.
- Alternativas digitales, humanas, híbridas y no-software.
- Validación de problema, solución, willingness-to-pay y Minimum Sellable Product.
- Halterofilia como primer caso técnico de investigación para Movement Analysis.

## Out of scope at inception

- [Decisión] Construir software, seleccionar un stack o diseñar una aplicación final.
- [Decisión] Implementar computer vision, pose estimation o análisis de movimientos.
- [Decisión] Diagnóstico, tratamiento, evaluación clínica o garantías de prevención de lesiones.
- [Decisión] Declarar que 40+ necesita entrenamiento diferente sin evidencia.
- [Decisión] Activar una Capability canónica o promover Asset Candidates.
- [Decisión] Modificar otros Labs o proyectos.

## Operating principles

1. [Decisión] Problem-first, evidence-first, sell-before-build.
2. [Decisión] La app compite con todas las alternativas de solución.
3. [Decisión] Una observación del fundador no cuenta como demanda externa.
4. [Decisión] El feedback técnico futuro debe incluir aciertos, mejoras y límites de confianza, no sólo errores.
5. [Decisión] La incertidumbre debe poder producir abstención explícita.
6. [Decisión] La complejidad documental y experimental será proporcional al estado `explorando` y al operador SOLO.

## Founder authorization

- [Decisión] Priority: `PRIMARY_ACTIVE_LAB` for commercial discovery; this is not a full-time allocation.
- [Decisión] Capacity: `3–5 h/week`.
- [Decisión] Phase 1 — Problem Validation is authorized.
- [Decisión] The boundary above is approved without changes.

## Initial gates

| Gate | Criterio |
|---|---|
| Problem gate | Problema frecuente e importante confirmado por evidencia de usuarios del segmento |
| Solution gate | Una alternativa muestra valor percibido superior a las actuales |
| Payment gate | Evidencia conductual de disposición a pagar |
| MSP gate | Oferta manual o productizada mínima entregable responsablemente |
| Software gate | Evidencia de que software aporta valor adicional suficiente frente a la alternativa manual/híbrida |
