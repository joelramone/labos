# Research

Investigación, experimentos, datos y reportes de LabOS.

## Estructura

- **experiments/** — Experimentos activos y completados.
- **datasets/** — Datos recopilados para análisis.
- **notebooks/** — Notebooks de análisis y exploración.
- **reports/** — Reportes de investigación finalizados.

## Regla

Toda investigación debe producir un activo reutilizable. Ver `business-principles.md`.
