# Assets

Activos reutilizables generados por investigación y trabajo en LabOS.

## Categorías

- **knowledge/** — Activos de conocimiento: guías, frameworks, metodologías.
- **technical/** — Activos técnicos: componentes, librerías, herramientas.
- **educational/** — Activos educativos: cursos, tutoriales, material didáctico.
- **commercial/** — Activos comerciales: propuestas, decks, casos de estudio.
- **data/** — Datasets, modelos entrenados, configuraciones.

## Regla

Todo activo debe tener una hipótesis de producto o monetización documentada. Ver `business-principles.md`.
